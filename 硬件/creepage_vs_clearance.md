# 爬电距离 vs 电气间隙

## 定义

| 术语 | 英文 | 路径 |
|---|---|---|
| **爬电距离** | Creepage Distance | 沿绝缘材料**表面**的最短路径 |
| **电气间隙** | Clearance | 通过**空气**的最短直线距离 |

## 直观理解

```
  导体A ~~~~~~~~~~~~~~~ 导体B
          \         /
   空气    \       /   ← 电气间隙（空中直线）
            \     /
   ———————————————————  PCB 表面
    ~~~~~~~~~~~~~~~       ← 爬电距离（贴着表面走）
```

**爬电距离 ≥ 电气间隙**，因为沿表面绕行不会比空中直线更短。

## 影响因素

| 因素 | 爬电距离 | 电气间隙 |
|---|---|---|
| 工作电压 | ✓ | ✓ |
| 污染等级 (Pollution Degree) | ✓ 影响大 | 影响小 |
| CTI (相比漏电起痕指数) | ✓ | — |
| 冲击耐压 (Impulse Voltage) | — | ✓ 主要决定因素 |
| 海拔高度 | — | ✓ 海拔越高间隙需越大 |
| 绝缘材料表面形状 | ✓ 开槽可增加有效爬距 | — |

## 关键概念

- **污染等级**：PCB 一般按 Pollution Degree 2（非导电污染，偶有凝露）
- **CTI**：材料表面抗漏电起痕能力，FR-4 通常在 PLC 3~4 档（175V~250V）
- **开槽**：在 PCB 上在两导体间开槽，强迫爬电路径绕行，是增加爬电距离的常用手段

## 在电机驱动中的典型场景

- **高压侧与低压侧隔离**：MOSFET 驱动的高压区域（如 310V DC Bus）与 MCU 低压侧之间，需满足加强绝缘要求
- **相间隔离**：U/V/W 相输出之间，属于功能绝缘
- **光耦/隔离器件下方**：不可敷铜，确保爬电距离不被破坏
